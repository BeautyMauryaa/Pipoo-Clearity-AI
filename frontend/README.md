# Clarity AI Frontend

The Next.js frontend for Clarity AI, a career-clarity and focus platform that is currently in development.

The current landing page is composed of reusable sections covering the problem, solution, how the product is intended to work, who it is for, and calls to action. The wider application is still evolving alongside the backend.

## Stack

- Next.js 16
- React 19
- Tailwind CSS
- Framer Motion
- Lucide React icons

## Run locally

Requires Node.js 20.9 or newer.

From the repository root:

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Available scripts

```bash
npm run dev    # Start the development server
npm run build  # Create a production build
npm run start  # Serve the production build
npm run lint   # Run ESLint
```
